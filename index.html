VPN CLI Termux Repository

Custom APT repository for installing and managing vpn-cli directly inside Termux.

Quick Install (Termux)

Add this repository source to your Termux setup and install the package:

curl -sL https://jjjm03299-wq.github.io/termux-apt-repo/vpn-cli.list -o $PREFIX/etc/apt/sources.list.d/vpn-cli.list
pkg update
pkg install vpn-cli
