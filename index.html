VPN-CLI Termux APT Repository

Official APT package repository for vpn-cli on Termux.

Quick Install (Termux)

curl -sL https://jjjm03299-wq.github.io/termux-apt-repo/vpn-cli.list -o $PREFIX/etc/apt/sources.list.d/vpn-cli.list
pkg update
pkg install vpn-cli
